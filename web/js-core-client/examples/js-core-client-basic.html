@deephaven/js-core-client

Logs in anonymously, fetches a scope variable (default my_table), subscribes to a viewport, and renders the rows live. Examples to run in the console first:

  • Static: my_table = empty_table(42).update_view(['I=i', 'J=i*i', 'S="row"+i'])
  • Ticking: t = time_table("PT1s").update_view(['I=ii']) — open ?table=t
  • Tail viewport: append &tail=10 to see the last 10 rows.
  • Server-side filter: append one or more &filter=... params, e.g. ?table=my_table&filter=I%3E%3D50 or ?table=my_table&filter=I%3E10&filter=J%3C1000.
  • Server-side sort: append one or more &sort=... params, prefix the column with - for descending, e.g. ?table=my_table&sort=-I or ?table=my_table&filter=I%3E50&sort=-J.
