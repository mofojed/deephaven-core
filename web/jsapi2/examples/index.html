@deephaven/jsapi examples

These pages use @deephaven/jsapi, the TypeScript client for Deephaven, and its immutable table API. The client loads the server's protocol bindings from /jsapi/dh-core2.js; the original API remains at /jsapi/dh-core.js. In an application, install the package from npm and import it: 

import { CoreClient } from '@deephaven/jsapi';

const client = new CoreClient('http://localhost:10000/');
await client.login({ type: CoreClient.LOGIN_TYPE_ANONYMOUS });
const table = await client.getObject({ name: 't' });
const sorted = await table.sort('X');
const subscription = sorted.createViewportSubscription({ rows: { first: 0, last: 49 } });
subscription.addEventListener('updated', data => render(data));

Here, an import map points @deephaven/jsapi at a bundled copy the server serves next to these pages. The CoreClient is also on window.dhjs in the browser console. If the server uses a pre-shared key, add ?psk=<key> to the URL; otherwise each page asks for it.

Examples

  • Create a table and read a snapshot of it
  • Subscribe to a viewport of a ticking table, with paging
  • Filter, sort, aggregate and join, deriving new tables from one source
  • Run Python or Groovy code, then fetch and display the tables it creates
